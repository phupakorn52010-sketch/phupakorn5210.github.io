# บ้านใหม่แม่ก๊ะเหนือ Promo Website

Static website for promoting the Mae Ka Nuea house sale.

## Files

- `index.html` main webpage
- `styles.css` responsive design
- `script.js` Facebook/Web Share button
- `assets/` copied house photos
- `assets/og-cover.jpg` 1200x630 social preview image

## Facebook sharing

Upload this folder to a public host first. Facebook needs a public URL to read the `og:title`, `og:description`, and `og:image` metadata. After hosting, change `assets/og-cover.jpg` in `index.html` to the full public image URL for the best Facebook preview.
